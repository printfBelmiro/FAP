Conheça a FALP

A FALP — Ferramenta de Apoio Linguístico para Programação — é um projeto de pesquisa dentro do ecossistema FAP. Seu foco é o apoio linguístico: o inglês técnico da programação e a relação entre a linguagem natural e o código.

No site original, você cola uma mensagem de erro em inglês e recebe a explicação palavra por palavra.

Protótipo em construção.

FALP

Ferramenta de Apoio Linguístico para Programação. Cole uma mensagem de erro em inglês e entenda o que ela quer dizer, palavra por palavra.

Esta versão usa uma base de erros inicial feita para a FAP, não a base do site original.

O que a FALP faz?

Ela explica, em português, mensagens de erro escritas em inglês, mostrando o que cada palavra quer dizer.

Quais linguagens ela entende?

Python e JavaScript. No modo automático, ela tenta reconhecer a linguagem pela própria mensagem.

Por que algumas mensagens não são reconhecidas?

A base de erros ainda é pequena. Nesses casos, você vê só a tradução palavra por palavra.

Onde fica salvo o meu histórico?

Somente neste navegador, neste aparelho. Se você apagar os dados do navegador, ele some.
