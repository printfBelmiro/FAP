
# FAP — Ferramenta de Apoio à Programação

**FAP (Programming Support Tool)** is an educational technology initiative focused on making programming education more accessible to students who are beginning their journey in Information Technology.

## About

Learning to program can be challenging, especially for students encountering programming concepts, technical terminology, and development tools for the first time.

FAP was created with the goal of making this learning process more accessible through educational resources, digital tools, and initiatives that support students throughout their development.

The project aims to grow into an educational ecosystem that brings together different approaches to programming education and technical learning.

## Main Goals

- Make programming concepts easier to understand.
- Provide accessible and organized learning materials.
- Support students who are new to programming.
- Develop digital tools that complement the learning process.
- Encourage independent learning and technical development.

## Projects

### FALP — Ferramenta de Apoio Linguístico para Programação

FALP is a project focused on helping beginner programmers understand technical English commonly found in programming environments, software documentation, development tools, and error messages.

Originally developed as an independent project, FALP became part of the FAP ecosystem as the broader initiative took shape.

## Development

FAP is an ongoing initiative. Its platform, educational materials, and tools are being developed progressively.

New resources and features will be introduced as the project evolves.

## Vision

To build an educational ecosystem that helps students develop programming skills, gain confidence with technology, and access learning opportunities regardless of their starting point.
